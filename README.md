# Rifa Digital

O deploy gratuito usa a Render com Postgres. As reservas e os comprovantes ficam no banco, não no disco. O banco gratuito expira 30 dias depois de criado. O site pode demorar cerca de um minuto na primeira abertura depois de ficar parado.

Para publicar, abra:

https://render.com/deploy?repo=https://github.com/pvanderson297-debug/rifa-digital

A senha do painel fica na variável `RIFA_ADMIN_PASSWORD`.
